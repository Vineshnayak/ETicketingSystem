# E-Ticketing System (Java Swing)

A simple desktop application to book tickets by entering **name, age, and destination**. The booked ticket details are displayed on the screen, and users can also clear the form.

### Features

* Java Swing GUI
* Input validation
* Ticket details display
* Clear / reset option

### Run

```bash
javac ETicketingSystem.java
java ETicketingSystem
```
